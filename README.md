# Deploy Noteline

One-click deployment manifests for **Noteline** — a self-hosted web annotation tool. Teams leave highlights,
comments, and reactions on any webpage via a `<script>` embed tag.

> **TODO:** link the actual Noteline source repo URL here once you decide whether/how it's referenced publicly.

This repo intentionally contains **no application source code** — only deployment manifests. Every manifest here
deploys the published container image:

```
sololevelingquest/noteline:latest
```

Noteline is a single Go binary (API + admin SPA + embeddable widget, all in one process) backed by **PostgreSQL 17**.
There is no other required infrastructure (no Redis, no object storage).

"One-time setup required" means the platform doesn't support a purely file-based one-click button — see the linked
doc for the (single, one-time) manual step the repo owner needs to do before the button works for end users.

Netlify was considered and intentionally excluded: it's a static-site/serverless-functions platform and can't run a
stateful Go binary + Postgres backend the way this app requires.

## Required environment variables

All manifests below set these automatically except where noted. If you're deploying by hand, see `.env.example` in
the Noteline source repo for the canonical list.

| Variable | Required | Notes |
|---|---|---|
| `DATABASE_URL` | Yes | Postgres DSN. Auto-wired to each platform's managed/companion Postgres service. |
| `SECRET_KEY` | Yes | JWT signing secret. Auto-generated by every manifest that supports it. |
| `NOTELINE_ENCRYPTION_KEY` | Yes | Base64 AES-256 key encrypting notification credentials at rest. Auto-generated by every manifest that supports it. Losing it makes saved notification credentials unrecoverable. |
| `PUBLIC_BASE_URL` | Yes | Externally-reachable base URL. **Most platforms assign your domain only after the first deploy** — see each platform's doc for how (or whether) this gets wired automatically, and update it by hand if not. |
| `PORT` | No (default `8080`) | HTTP listen port. |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | No | First-run admin account seed. Change the password after first login. |
| `WHATSAPP_WEBHOOK_SECRET` | No | Only needed if you use the WhatsApp notification channel. |
